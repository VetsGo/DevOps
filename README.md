# DevOps

## Опис
Пакет my_package — це простий приклад Python-бібліотеки, що містить функцію hello(), яка повертає повідомлення з вітанням.

## Встановлення
Виконайте команду: pip install my_package
Або якщо використовується локальне сховище PyPI то виконайте цю команду: pip install --index-url http://localhost:3141/user/dev/simple/ my_package
